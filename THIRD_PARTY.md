# Third-party software

This repository contains only its own scripts, skills, configuration and documentation (MIT, see [LICENSE](LICENSE)),
plus the example project in `examples/strike-arena` (MIT, generated by the pipeline; it depends on three.js, Vite and
Vitest via npm). None of the components below is redistributed: the install scripts download them from their own
sources, under their own licenses.
